# 07 — Coach Curriculum & Age-Band Delivery Methodology

> **Purpose:** The actual teaching mechanics — how coaches should deliver content at each age band, sourced from World Athletics, BWF, grassroots boxing federations, and Swim England. This is the "how to coach," complementing `06_talent_id_methodology.md`'s "what to test."

---

## 1. Cross-Sport Progression Principle (Consistent Across All Frameworks)

```
Simple → Coordinated → Moving → Variable/opposed → Modified game/event application
```

Universal teaching sequence:
1. Establish safe posture/body position before speed, force, distance, or opposition
2. Teach one technical component at a time, short cue + clear demonstration
3. Practise in predictable conditions (stationary target, fixed direction, slow object)
4. Add movement and coordination
5. Add variability and decision-making
6. Apply in a modified game/event
7. Observe and adapt — progress only when the child is comfortable and safe, not because of age alone

## 2. Tier 1 (Ages 6–9, FUNdamentals) — Teaching Method

### Core coaching principles
- **One movement cue at a time**, short child-friendly phrase (e.g. "land like a ninja") over technical explanation
- **Stations and small-sided games instead of queues** — maximize repetitions per child
- **Progression by control/quality, not by increasing height/distance/speed**
- **Games-based delivery** (tag, relays, obstacle courses, target games) over repetitive drilling
- **Observation checklists are for deciding what to teach next — never for labeling a child "talented" or "untalented"**

### Skill-by-skill cues (sample)
| Skill | Coach teaches | Child-friendly cue |
|---|---|---|
| Running | Tall posture, forward gaze, arm-leg opposition | "Eyes ahead," "arms like train tracks" |
| Jumping | Prep position, two-foot take-off, soft landing | "Sit back, then spring," "land like a ninja" |
| Throwing | Side-on prep, step with opposite foot, follow-through | "Side to target, step, throw, reach" |
| Catching | Ready hands, tracking, soft absorption | "Eyes on the ball," "make a window" |
| Balance | Centre of mass over base of support | "Freeze like a statue," "find your balance again" |

### Session structure (45–60 min)
```
Arrival game (5-8 min) → Skill exploration (8-10 min) → Skill practice (10-15 min) 
→ Skill game (12-18 min) → Challenge/reflection (5-8 min) → Close/handover (2-3 min)
```

### What to avoid at this stage
Long lines/queues; repeated maximal sprinting/jumping for fatigue; adult-style conditioning; early specialization; public rankings or body-shaming; treating movement screening as irreversible talent selection; using advanced technical terms when a simple cue works.

## 3. Tier 2 (Ages 9–12, Learn-to-Train) — Sport-Specific Foundations

### Athletics (World Athletics Kids' Athletics framework)
Delivered through short games, relays, obstacle tasks, target challenges — not adult-event specialization.
- **Running:** posture/rhythm → starts/acceleration → change of direction → relay skills
- **Jumping:** landing/take-off basics → horizontal jump → vertical jump → rhythm/repeated jumps
- **Throwing:** safety/sending rules → basic linear throw → accuracy then distance → event-like adaptation (foam vortex/javelin, light shot-push)

### Badminton (BWF Level 1 model)
- Movement without racket → racket familiarity → hand-fed contact → cooperative rally → modified court rallies → simple game rules → introductory tactics
- Priority: broad racket skill and movement — **not** advanced deception, powerful smashes, or adult-style match volume

### Boxing — strictly non-contact/controlled at this age
- Rules/respect/safety → athletic stance → guard → footwork → straight punches (pads only) → basic defence → punch combinations → controlled game application
- **Hard safeguards:** no hard sparring, no deliberate head contact, no weight-loss practices, gender-inclusive non-humiliating feedback, do not normalize aggression as identity

### Swimming (Swim England Learn to Swim Framework)
- Water confidence/safe entry → submersion/orientation → floating/body shape → rotation → push/glide → kicking → basic arm action → breathing → whole-stroke coordination → water safety/self-rescue
- **Should be a dedicated aquatic session with qualified supervision** — not folded into a generic dry-land multisport circuit

### Example 60-minute multisport rotation (9–12 beginner group)
```
0-8 min:   Tag/traffic lights/mirror movement (running, awareness, fun)
8-20 min:  Athletics stations (sprint, jump-and-stick, foam-ball target throw)
20-32 min: Badminton movement + low-net rally
32-44 min: Non-contact boxing footwork + pads
44-55 min: Skill game circuit (relay, target, shuttle tap, balance)
55-60 min: Reflection, hydration, parent/school handover
```

## 4. Coach Education Curriculum Structure

Cross-checked from ISCF, UK Coaching, England Athletics, England Squash, World Rugby, BWF — converging model:

- **Safeguarding: mandatory prerequisite**, gates all further content
- **Format (working hypothesis, not yet India-validated):** 20–40 blended learning hours — online modules + tutor-led workshop + supervised field practice (2–4 observed sessions) + portfolio
- **Assessment: competency-based** ("competent"/"not-yet-competent"), not attendance-based
- **Registry:** verifiable coach ID with qualification level, sport, expiry, safeguarding status
- **Progression:** Assistant → Grassroots → Development → Advanced/Performance (mapping to NCAB's proposed tiers)
- **Renewable license** (2–3 years, working hypothesis), tied to safeguarding recertification and CPD

**See `02_coach_credentialing.md` for the full India-specific curriculum additions and the Direction A/B fork analysis.**

## 5. What a Credible Practical Assessment Should Observe

A trained assessor should verify whether a candidate coach can:
- Conduct a simple risk/equipment check
- Explain, demonstrate, and adapt an activity clearly
- Keep children active rather than standing in lines
- Use inclusive, non-humiliating communication
- Adjust task difficulty for different confidence levels
- Recognize a safety concern and respond correctly
- Close with reflection, feedback, and safe handover to parents/school

A strong program allows a genuine **"not yet competent"** outcome with mentoring and reassessment — not automatic certification for attendance.
